Local Scribe

Offline transcription and transcript validation for research · version {{ version }}

Credits

Local Scribe was created by Jeremy Riel at the UIC TRAILblazer Lab, University of Illinois Chicago.

Built for researchers who work with human-subjects recordings that cannot be uploaded to a commercial transcription service.

What this application does

Local Scribe turns audio and video recordings into transcripts, and then gives you a workbench for correcting them against the audio. The intended workflow is four steps:

  1. Create a project for a study or interview wave, and record its metadata: investigator, IRB protocol, participant scheme, consent notes, and a glossary of names and jargon.
  2. Add recordings in essentially any common audio or video format. Audio is extracted from video automatically. Original files are never modified.
  3. Transcribe with OpenAI's Whisper models running on this machine, watching detailed progress, throughput, and time estimates in the console.
  4. Validate and correct each transcript in a page of its own, with the audio playable in the window, a clickable time ribbon, and click-a-word-to-hear-it playback. Set up your speakers, then tag each speaking turn with one click or a number key; names and colours carry through to the exports. Find and replace fixes a recurring error across the whole transcript. Misspellings are underlined in red and probable transcription slips in blue. When the human pass is done, press Re-timestamp to bring the word timings and caption files back into agreement with the corrected text, then export.

Exports are written for both reading and further work: plain text and Markdown for analysis and coding, Word (.docx) for circulation and review, and timestamped WebVTT and SubRip caption files for video software.

Why this is safer for protected data

Recordings and transcripts never leave this computer. There is no cloud service, no API key, no user account, and no upload step. Transcription happens in this process, on this machine's own CPU or GPU.

No third-party services

Commercial transcription tools send audio to a vendor's servers, where it is processed and often retained. That is usually incompatible with an IRB protocol covering identifiable human-subjects data. Local Scribe removes the transfer entirely, so there is no vendor, no data processing agreement to negotiate, and no third-party retention question to answer.

No telemetry, no external assets

This interface loads no fonts, scripts, stylesheets, or images from the internet. Everything it renders is served from this application's own folder. Nothing measures or reports your usage. You can confirm this by viewing the page source: there are no external URLs in it.

One deliberate network request, then sealed

Whisper's model weights have to come from somewhere, so AI Settings has an explicit download action for them. That is the only outbound request the application makes. Once the model is on disk, engaging the offline lock blocks all non-loopback network access inside this process at the socket level, so it cannot reach the network even by mistake.

Offline lock is currently {% if engine.offline_lock %} engaged. {% else %} off. Engage it in AI Settings once your models are downloaded. {% endif %}

Loopback only, isolated from other local apps

The server binds 127.0.0.1 exclusively, so it is not reachable from your network. It listens on a fixed, uncommon port and refuses to move to another one, and it rejects requests originating from any other local application, so several local tools can run side by side without interfering with each other.

Plain files you control

There is no database. Each project is a folder of JSON, media, and exported documents, so you can inspect it, copy it to an encrypted drive, back it up, or recover a transcript with a text editor. Deleting a project deletes its files.

Provenance travels with the transcript

Every export records the model used, the language, the review status, and the project's investigator and protocol number, so a transcript remains interpretable as a research record rather than as an anonymous text file.

What this does not do Local Scribe reduces the data-transfer risk. It does not encrypt your disk, manage access to this computer, or de-identify transcript content. Machine transcripts also contain errors, including plausible-sounding ones, so a human pass against the audio remains necessary before analysis or quotation.

How it works

Transcription
OpenAI Whisper weights executed by faster-whisper on the CTranslate2 runtime, with word-level timestamps and Silero voice-activity detection.
Media handling
PyAV, which bundles its own FFmpeg libraries, so no separate ffmpeg installation is needed to read video containers.
Re-timestamping
After a human edit, word timings are re-derived by aligning the corrected text against the model's original timed words and transferring timings across that alignment. Unchanged text keeps its exact timings; rewritten passages are distributed proportionally and reported in the console for spot-checking.
Proofreading
A 124,000-word English dictionary derived from SCOWL, covering both American and British spellings, bundled with the application and used entirely offline. Your project glossary and any words you accept are added to it. The blue layer flags likely transcription slips -- doubled words, repeated-phrase loops, a/an mismatches -- and deliberately does not check grammar, because verbatim speech is full of fragments and false starts that are correct exactly as transcribed.
Interface
Python, FastAPI, and plain HTML, CSS, and JavaScript. No frameworks fetched from the internet.
